
Экспресс-курс составленный gemini с практическими заданиями.

План курса:
Неделя 1: Ядро Языка и Мышление в Стиле Python
Цель: Отказаться от привычек 1С там, где это необходимо, и освоить базовый синтаксис, структуры данных и идиомы Python до автоматизма.
День 1: Окружение, Первая Программа и Контроль Версий
Темы: Установка Python 3.x, VS Code, терминал.
Git: Инициализация репозитория (git init). Цикл git add -> git commit. Почему это критически важно: Ни одна строчка профессионального кода не пишется без системы контроля версий. Это как "Провести документ" для вашего кода.
Практика: Создать репозиторий, написать "Hello, world!", сделать первый коммит.
День 2: Переменные, Типы, Строки и Комментарии
Темы: Базовые типы (int, float, str, bool, None). Динамическая типизация.
Работа со строками: f-строки. Ключевые методы строк: .strip(), .split(), .join(), .lower(), .upper(), .replace(), .startswith(), .endswith(). Почему это критически важно: В 1С вы используете СокрЛП, СтрЗаменить и т.д. В Python работа со строками ведется через эти методы, и они используются постоянно.
Комментарии: # для пояснений "почему" и """Docstrings""" для документации "что".
Практика: Написать скрипт, который "чистит" ФИО (убирает лишние пробелы, приводит к нужному регистру).
День 3-4: Коллекции — Новый Взгляд на Данные
Темы: list, tuple, dict, set. Методы коллекций (append, pop, get и т.д.). Срезы.
Итерация: Цикл for item in collection:. Получение индекса и значения через enumerate(). Итерация по словарю (.keys(), .values(), .items()).
Практика: Смоделировать документ "ПоступлениеТоваров" (шапка в виде словаря, табличная часть в виде списка словарей).
День 5-6: Логика, Циклы и "Питонический" Способ
Темы: Условия if/elif/else. Циклы for/while. Управление циклами: break, continue и конструкция for...else.
List/Dict/Set Comprehensions: [x*x for x in range(10) if x % 2 == 0]. Почему это критически важно: Это одна из самых узнаваемых и часто используемых конструкций Python для создания коллекций. Пропустить ее — значит не понять язык. Это ваш новый "Запрос" для простых выборок из коллекций.
Практика: Используя list comprehension, из списка товаров получить список только названий тех товаров, у которых цена выше 1000.
День 7: Функции, Области Видимости и Отладка
Темы: def, return, аргументы (позиционные, именованные, по умолчанию). Type hints, Docstrings. Области видимости (LEGB).
Основы отладки: Использование print() для быстрой проверки. Встроенный отладчик: breakpoint() и использование отладчика в VS Code (точки останова, пошаговое выполнение F10/F11). Почему это критически важно: Вы не можете писать код, не умея его отлаживать. Это как "Отладчик" и "Табло" в Конфигураторе.
Задание на неделю 1: Скрипт обработки "грязных" данных. Разбит на функции. Использует comprehensions для фильтрации. Каждый этап разработки фиксируется коммитом.
Неделя 2: Структурирование Проекта и Работа с Внешним Миром
Цель: Перейти от однофайловых скриптов к многомодульным проектам. Научиться работать с файловой системой, ошибками и внешними библиотеками.
День 8-9: Продвинутые Функции и Модули
Темы: *args, **kwargs. Лямбда-функции (lambda): lambda x: x * 2. Функции высшего порядка: map(), filter(). Почему это критически важно: lambda используется повсеместно для передачи простых функций "на лету", например, для сортировки sorted(..., key=lambda ...).
Модули и Пакеты: import, from ... import. Создание структуры проекта. Файл __init__.py.
Практика: Разбить код из задания 1 на модули data_loader.py, processing.py, main.py.
День 10-11: Файлы, Ошибки и Контекстные Менеджеры
Темы: Обработка исключений try...except...else...finally. raise.
Работа с файловой системой: Модуль os (устаревший способ) и модуль pathlib (современный, объектно-ориентированный способ). Почему это критически важно: pathlib решает множество проблем с путями в разных ОС (/ vs \). Это стандарт для новой кодовой базы.
Контекстный менеджер with: with open(...) as f:. Гарантированное управление ресурсами.
День 12-13: Экосистема: venv и pip. Работа с Данными
Темы: Виртуальные окружения venv. Менеджер пакетов pip. requirements.txt.
Форматы данных: Встроенные модули json и csv для чтения/записи.
Работа с датой и временем: Модуль datetime. Создание объектов datetime, timedelta. Форматирование: strftime (объект -> строка) и strptime (строка -> объект). Почему это критически важно: Любая бизнес-логика работает с датами. Это аналог функций Формат и Дата в 1С.
День 14: Инструменты Качества Кода
Темы: Линтеры (flake8). Форматтеры (black). Почему это критически важно: Эти инструменты автоматически обеспечивают чистоту и единый стиль кода, снимая с вас эту головную боль. В командной работе это не опция, а необходимость.
Задание на неделю 2: Проект "Анализатор лог-файла". Скрипт читает текстовый лог, парсит строки (используя методы строк и datetime.strptime), находит ошибки, агрегирует статистику и записывает отчет в JSON и CSV. Проект структурирован по модулям, использует venv, requirements.txt, проходит проверку flake8 и black.
Неделя 3: Объектно-Ориентированное Программирование (ООП) — Смена Парадигмы
Цель: Научиться мыслить не данными и процедурами, а объектами и их взаимодействиями.
День 15-17: Классы, Объекты и "Магия"
Темы: class, self, __init__, атрибуты, методы.
Магические методы: __str__ (для print), __repr__ (для отладки), __eq__ (для сравнения ==).
Практика: Создать класс Employee с атрибутами и методом для расчета зарплаты.
День 18-19: Наследование и Полиморфизм
Темы: Создание дочерних классов. Переопределение методов. super().
@property: Создание "вычисляемых" полей, которые выглядят как атрибуты.
@staticmethod и @classmethod: Методы, не привязанные к экземпляру.
Принципы SOLID (обзорно): Единая ответственность (S), Открытость/закрытость (O).
День 20-21: Тестирование — Гарантия Качества
Темы: Фреймворк pytest. Написание простых тестов. Структура "Arrange-Act-Assert".
Почему это критически важно: Код без тестов — ненадежный код. Тесты позволяют проводить рефакторинг без страха что-то сломать.
Задание на неделю 3: Рефакторинг задания 2 в ООП-стиле. Создать классы LogEntry, LogParser, ReportGenerator. Покрыть ключевую бизнес-логику (например, парсинг одной строки) тестами pytest.
Неделя 4: Погружение в Экосистему и Реальные Задачи
Цель: Увидеть, как Python применяется для решения высокоуровневых задач, и выбрать направление для дальнейшего развития.
День 22-23: Работа с Сетью и API
Темы: Основы HTTP. Библиотека requests (get, post). Работа с JSON ответами.
Практика: Написать скрипт, получающий курсы валют с публичного API.
День 24-26: Анализ Данных с pandas — ваш новый язык запросов
Темы: DataFrame и Series. Чтение данных (pd.read_csv, pd.read_json).
Манипуляция данными: Индексация, фильтрация (маски), groupby, agg. Почему это критически важно: pandas заменяет 90% рутинных циклов по обработке табличных данных. Это ваш мощнейший инструмент для любой аналитики.
Практика: Загрузить данные о курсах валют в DataFrame и рассчитать среднее/максимальное значение.
День 27-28: Знакомство с Базами Данных
Темы: Основы SQL. Встроенная БД sqlite3. Выполнение запросов.
Обзор ORM: Краткое знакомство с SQLAlchemy Core — как писать запросы к БД, используя объекты Python, а не строки SQL.
День 29-30: Финальный Проект и Дальнейшие Шаги
Финальный проект (Capstone Project): Объединить все. Написать консольное приложение:
По сети (requests) забирает данные (например, из API курсов валют).
Сохраняет сырые данные в SQLite базу данных.
С помощью pandas читает данные из БД, проводит анализ (группирует, считает статистики).
Генерирует отчет в виде файла.
Весь проект находится в Git, имеет тесты на pytest, использует venv, отформатирован по black.
Подведение итогов: Обзор специализаций (Backend, Data Science, DevOps) и какие библиотеки учить для каждой из них.
